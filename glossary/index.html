研究の設計

相関

二つの変数が一緒に変わる傾向。片方を変えたときにもう片方が変わる、という因果関係と同じではありません。

例と注意点

架空例：通知の回数と疲労感が関連していても、多忙さが両方に関わった可能性があります。

出典：SRC302 · 25.2.1

  • 相関と因果の違い
因果関係

ある要因の違いが結果に影響を与える関係。単なる関連や、前後の変化と区別して検討します。

例と注意点

架空例：机を片づけた後に作業量が増えても、仕事の種類や締め切りが変わっていないかを確認します。

出典：SRC302 · 25.2 / 25.5

  • 相関と因果の違い
  • 自分で習慣を試すには
交絡

比較したい要因と結果の関係に、両方に関わる別の要因の影響が混ざること。調整後にも未測定の交絡が残り得ます。

例と注意点

架空例：忙しい人ほど通知も疲労感も多いなら、多忙さが第三の要因の候補になります。

出典：SRC302 · 25.2.1

  • 相関と因果の違い
ランダム化

介入などの割り付けを偶然の仕組みで決めること。参加者や担当者の判断で比較群が決まることを防ぎます。

例と注意点

参加者を社会全体から無作為に選ぶこととは別です。また、脱落や測定の偏りまで自動で消すわけではありません。

出典：SRC302 · 25.2

  • 相関と因果の違い
アウトカム

研究で結果として測る項目。何を、どの尺度で、いつ測ったのかを確認します。

例と注意点

架空例：直後の気分、翌日の記憶、半年後の成績は、同じ成果としては扱えません。

出典：SRC304 · 15.2

  • メタ分析の読み方
  • 動物研究は人にも通じる？
一般化

ある対象・条件の結果を、別の人や場面に広げて考えること。研究内の比較の妥当性とは区別します。

例と注意点

架空例：学生の短い実験課題から、会社員の長期的な仕事の成果をそのまま予測しません。

出典：SRC302 · SRC304 · 25.1.1 / 15.2

  • 海外の研究は自分にも通じる？

数字の読み方

効果量

差や関連の大きさを表す指標。点数差、割合の比、標準化平均差など、指標ごとに意味が違います。

例と注意点

架空例：1点の差と1パーセントポイントの差は、同じ「1」でも単位が違います。

出典：SRC303 · 6.4 / 6.5.1

  • 効果量の読み方
標準化平均差

平均の差を標準偏差などで標準化した指標。異なる尺度の研究をまとめる場合などに使います。

例と注意点

架空の単純化した例：5点差÷標準偏差10点=0.5。50％の改善という意味ではありません。

出典：SRC303 · 6.5.1.2

  • 効果量の読み方
  • キャッシュレスで使い過ぎる？
相対差と絶対差

元の値に対する比で見る変化と、元の尺度で差を取る変化。両方を見ると、大きさを解釈しやすくなります。

例と注意点

架空例：2％から1％へ減ると、相対的には50％減、絶対的には1パーセントポイント減です。

出典：SRC303 · SRC304 · 6.4 / 15.4

  • 効果量の読み方
信頼区間

推定値の不確実性を示す区間。通常の95％信頼区間は、同じ作り方を繰り返す場合の区間の性質を表します。

例と注意点

真の値が今回の区間内にある確率や、個人が改善する確率と、そのまま同一視しません。

出典：SRC304 · 15.3.1 / 15.3.3

  • 効果量の読み方
  • p値0.05の意味
統計的有意性

定めた検定の基準を満たすかという判断。効果の大きさや、実生活で意味があるかとは別です。

例と注意点

有意でなかった結果も、「違いがないと確定した」とは限りません。推定の幅を確認します。

出典：SRC304 · 15.3.2

  • p値0.05の意味
  • 効果量の読み方
平均への回帰

極端な値を理由に選んだ後の測定が、より普段の値に近づく現象。介入の効果と取り違える場合があります。

例と注意点

架空例：特に調子の悪い日から記録を始めると、その後の戻りを新しい習慣の効果だと思うかもしれません。

出典：SRC302 · 25.6

  • 自分で習慣を試すには

研究の統合

システマティックレビュー

定めた問いと方法に沿って研究を探し、選び、評価する取り組み。数値の統合を行わない場合もあります。

例と注意点

レビューと書かれていることだけで、検索や選定が網羅的だったと判断しないようにします。

出典：SRC305 · Chapter introduction

  • メタ分析の読み方
メタ分析

複数の研究の結果を統計的にまとめる方法。研究の違いや、集められなかった結果も検討します。

例と注意点

架空例：同じ「学習法」でも、覚える単語数と試験合格率をどう扱ったかを確認します。

出典：SRC305 · Chapter introduction / 10.10

  • メタ分析の読み方
異質性

研究間で対象や方法、効果などが異なること。統合した平均だけでは違いが見えない場合があります。

例と注意点

架空例：現場Aで2点、Bで8点の差なら、平均5点だけでは現場差が伝わりません。

出典：SRC305 · 10.10

  • メタ分析の読み方
出版バイアス

研究が公表されるかどうかが、結果に関わることによって生じる偏り。読める研究だけが全体とは限りません。

例と注意点

架空例：10研究中、差が大きかった2研究だけが公表されると、紹介できる研究の顔ぶれが偏ります。

出典：SRC306 · 13.1–13.2

  • 出版バイアスとは
選択的報告

測定や分析をした結果の一部が、結果に応じて選んで報告されること。研究全体の未公表と区別します。

例と注意点

計画にある主要項目と、論文で強調された項目が一致するかを確認することが手がかりになります。

出典：SRC306 · 13.1–13.2

  • 出版バイアスとは
ファンネル図

研究ごとの効果と精度の関係を可視化する図。非対称な形だけで出版バイアスが確定するわけではありません。

例と注意点

非対称性の検定が明確でなくても、欠けた研究が存在しない保証にはなりません。

出典：SRC306 · 13.3.4.3–13.3.4.5

  • 出版バイアスとは

確認と更新

追試

元の主張を新しいデータで検討する研究。同じデータで同じ計算を行うこととは区別します。

例と注意点

元の研究と手順が似ているかだけでなく、どの主張を確かめられる比較なのかを確認します。

出典：SRC307 · Abstract / Introduction

  • 追試とは何か
事前登録

結果を確かめる前に、問いや分析の計画などを記録しておくこと。計画した分析と後から加えた分析を区別します。

例と注意点

途中の変更や探索は可能です。変えた内容と理由が分かる形で報告することが重要です。

出典：SRC308 · FAQ: changes / conditional analyses

  • 追試とは何か
  • 出版バイアスとは
  • 自分で習慣を試すには
WEIRD

西洋・高学歴・工業化・豊かさ・民主主義という特徴を持つ社会を表す語。研究対象の偏りを考える文脈で使われます。

例と注意点

国民性を固定的に説明するラベルではありません。どの集団を調べた研究かを確かめるための論点です。

出典：SRC309 · PubMed Abstract

  • 海外の研究は自分にも通じる？
訂正

公表済みの論文の内容を修正すること。誤記だけでなく、科学的な記述や方法に関わる場合もあります。

例と注意点

修正された箇所と、記事の結論に影響するかを区別します。訂正という表示だけで重要性は決まりません。

出典：SRC311 · Errata

  • 論文の訂正・撤回を確認する
撤回

重大な問題などを理由に論文を取り下げること。撤回の表示だけで、誠実な誤りと不正を区別することはできません。

例と注意点

懸念表明は撤回と同じ最終判断ではありません。元の通知を読み、理由と範囲を確認します。

出典：SRC311 · Retractions / Expressions of Concern

  • 論文の訂正・撤回を確認する
N-of-1試験

一人を単位とし、条件を複数回切り替えるなどして比較する研究。通常の生活日記とは設計が違います。

例と注意点

薬の自己調整などを試すための案内ではありません。短い感想の記録から治療効果を確定しません。

出典：SRC224 · PubMed Abstract
