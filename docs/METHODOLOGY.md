# 調査方法と確認範囲

更新: 2026-09-11。完成記事や個別の医療助言ではなく、研究テーマ・資料の探索と予備的な対応づけです。

## 調査段階の区別

前回は300回の検索、1105候補レコード、重要論文・指針68件の抄録中心のメモを作成しました。この履歴はdata/research/history/round2_coverage.jsonと旧briefs.jsonに保持しています。

第3回は出典未登録131テーマに対するEurope PMC検索262回、Crossrefでの重点題名検索102回、DOI照合・補足検索146回の合計510回です。507回が返却成功、3回が失敗しました。成功しても0件の場合や無関係な結果が含まれます。累計810回の実行履歴をliterature/catalog.jsonから辿れます。

文献の初公開日・刊行日は検索の制約として2026-09-11以前にしています。ただし年やオンライン公開日を提供者が異なる形で登録することがあり、記事で使う年は原論文でも確認します。Europe PMCの広い探索は上位8件、重点照合は上位5件、Crossrefの題名検索は上位3件であり、網羅的な系統的レビューではありません。

## 選別と読解

第3回は124資料を選別し、102件は抄録、22件は書誌のみの確認として記録しました。後者には訂正告知1件と書籍シリーズの章1件を含みます。書誌のみの結果はnullにし、似た題名のプレプリントの抄録を刊行版へ無条件で転記しません。

初期検索は概念が近いだけの無関係な結果を多く含むため、クエリのテーマIDをそのまま採用先にしていません。source_reviewsのtopic_idsが実際の採用対応です。対象・結果が部分的にしか対応しないものは背景資料や限定的な関連として記録しました。

重要な7資料は本文の指定箇所を追加確認しました。カフェイン、短い休憩、ハイブリッド勤務、光環境、習慣形成、禁煙、スマホのネット遮断です。研究登録、割付、脱落・遵守、対照群、収載研究の質、資金源等を確認できた範囲だけ記録しています。全文・全補足・全データの独立再解析や正式なAMSTAR 2・GRADE評価はしていません。

APIによる選択的な全文取得5件は3件成功・2件失敗でした。これと別に、取得できた出版社等のHTML本文の指定箇所4件を確認しています。全文の取得成功と全文の批判的評価完了は別です。原文キャッシュは公開正本に保存しません。

## 過大評価を避ける運用

支持・反証・無効果・条件差を分けます。相関と因果、人と動物、健康者と患者、個人と集団、短期と長期、自己報告と客観指標を区別します。複合介入から一要素だけの効果を切り出しません。同じ対象者や同じ研究の別版を独立した追試として数えません。

候補数はデータベースのレコード数で、DOIとPMID等の別レコードが同じ研究を指す場合があります。正式に登録する書誌のDOIは重複を防ぎますが、研究単位の重複・追跡系列の同一性の全件監査は今後の課題です。

索引で見つかった訂正・批判は残し、関連欄が空でも「訂正・撤回なし」と保証しません。本文まで確認した範囲はsource_assessments、資料とテーマの適合性はevidence、今回のメモはsource_reviewsに分けます。

## 順位づけと公開準備

出典は関連性・方法上の情報・確認範囲で調査の順番を付けます。真偽の確率や正式な確実性のランクではありません。50テーマの編集評価は主観的な仮説で、検索数・閲覧数・売上を測っていません。編集入力の正本はdata/editorial_assessments.jsonです。順位は派生ビューとして生成し、テーマの正本順序を変えません。

現時点の全テーマはpublication_ready=falseです。次は全文、補足、事前登録、効果量と不確実性、反証、訂正、日本への適用、安全性を主張単位で確認します。医療・依存・トラウマ等は専門的確認を経てから記事にします。生活例は説明用の想定場面と実際の研究対象を区別します。
