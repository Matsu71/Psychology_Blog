# ランキングの意味と計算方法

`scoring_version: work-priority-1.0` / 2026-09-11。

## 三つの順位を混同しない

1. **編集上の有力度**：一般読者に関係し、独立した記事の問いになりそうか。
2. **テーマ別の出典調査優先度**：どの資料から読み、照合すべきか。
3. **今後の調査順**：編集上の関心と根拠の不足を合わせた作業配分。

いずれも公開許可ではありません。全テーマの`publication_ready`はfalseです。

## テーマの有力度

50テーマのみ個別に仮説的な評価を行いました。日常との関連40％、行動・判断への接続25％、知的な関心・意外性20％、読者の広さ15％。各1～5を加重して100点換算します。

```text
score = 8×日常との関連 + 5×行動への接続 + 4×関心 + 3×読者の広さ
```

根拠は編集上の判断理由として保存します。検索ボリューム、SNS反応、閲覧数、広告収益を測ったものではありません。未評価250テーマは点数nullで、評価済み50より劣ると判定していません。同点には同順位を付け、表示順のみIDで固定します。

## テーマ別の出典優先度

**正しい確率や正式な研究の質の点数ではなく、調査に使う優先順位です。** 書誌だけ、抄録、本文指定箇所、未再評価を区別します。

関連性：5=問いに直接対応、4=対象・結果の一部が限定、3=関連する生活場面への間接資料、2=背景概念、1=訂正等。書誌のみでは題名による暫定値です。

方法上の情報：1=書誌のみまたは予備的小標本、2=観察・概説・基礎実験等の入口、3=比較設計や統合方法が記載される資料、4=指定した本文箇所から登録・比較・解析等を確認した重点資料。研究形式だけで効果が確実と判断しません。具体的な限界は別の文字項目に残します。古い資料で未再評価の場合はnullです。

読解段階：1=書誌、2=抄録、3=本文の指定箇所、4=全文・補足までの確認（今回は付与なし）。

```text
raw score = 10×関連性(最大5) + 7.5×方法情報(最大4) + 5×読解段階(最大4)
```

書誌のみは最大49、背景資料は最大55、索引上の未解決の訂正があるものは最大65に制限します。訂正告知そのものは根拠の優先順位から除外し、元論文の状態確認用として残します。撤回を示唆する索引情報がある場合も自動で推奨せず、確認待ちにします。索引が空でも「訂正・撤回なし」と認定しません。未評価レコードには順位を付けません。

この方法情報の尺度は簡易な一次選別です。妥当性を検証した心理尺度・GRADE・AMSTAR 2ではなく、順位に数点の差があっても質が厳密に優劣づけられたとは解釈しません。AMSTAR 2自身も全項目の合計得点を作る用途ではないと説明しています。[AMSTAR公式](https://amstar.ca/Amstar-2.php)

反証、無効果、条件差があることでは減点しません。肯定的な結果だけを優先するのを避けます。古さも一律に減点せず、年と更新調査の必要を明示します。引用数・有名誌・リンク数では加点しません。

総合出典一覧は、各資料が最もよく対応するテーマでの優先点を表示します。一つの点数を全テーマへ転用せず、実際の記事調査では必ずテーマ別の順位を使います。

## 次に調べる順番

```text
work priority = 55％×編集上の点数 + 45％×調査不足
```

調査不足は、出典未登録100、資料はあるが直接の読解なし90、旧読解メモはあるがテーマ適合性の再点検が必要75、関連する抄録まで65、本文指定箇所まで45という作業用の区分です。編集未評価のテーマは作業配分上50を仮置きし、編集点数そのものはnullを維持します。

資料が少ないから面白くない、資料が多いから高確実性、という計算はしません。出典未登録を単なる件数合わせで埋めることも避けます。並び順は`data/rankings`に保存し、正本の順序は変更しません。

編集判断の入力正本は`data/editorial_assessments.json`です。追加・修正後にビューを再生成します。旧読解メモがある資料は未読扱いにせず、適合性の再点検という状態で管理します。
