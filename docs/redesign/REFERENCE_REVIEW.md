# 参考サイトの比較

確認日：2026-09-14。対象は心理学、心身の健康、科学情報を扱う既存媒体です。従来のAI案を維持するための比較ではなく、入口・記事画面・文章量を作り直すために調べました。

## 採用する軸

**Psychology Todayのテーマ索引、Greater Goodの分野別導線、NHSの短い見出し、Simply Psychologyの記事内導線**を統合します。大分類→分野→記事という一つの体系に揃え、媒体ごとの装飾を寄せ集めません。

「人気が高い」「読みやすい」は同じ指標ではありません。今回は既存媒体の実際の構造と公開編集方針を比較しました。全サイトの同条件のアクセス解析・第三者ユーザーテストは取得しておらず、人気順・読みやすさ順位を実測したという主張はしません。媒体の自己申告読者数を、このサイトの実績や順位に転用しません。

## 文章・配色の補助基準

[NHSの文章方針](https://service-manual.nhs.uk/content/how-we-write)は、平易で直接的な言葉と読者の必要を重視しています。[NHSの配色ガイド](https://service-manual.nhs.uk/design-system/styles/colour)は文字・背景・操作・状態の役割を区別する参考としました。英語の文長目安や固有のブランド色を、日本語サイトの普遍的な正解とはしていません。

[Nielsen Norman Groupの生成AI文章のガイド](https://www.nngroup.com/articles/genai-write-for-the-web/)も、冗長さを減らし走査して読める文章にする補助資料です。古いウェブ読解研究の改善率を、このサイトで再現した数値として使いません。

## 一つの画面への統合

- 入口：8大分類。元の28分野をその下に整理し、300テーマの研究上のID・題名・順序は維持します。
- トップ：短い見出し、主記事、4件の導入記事、テーマ索引、6件の日常の疑問。長い宣伝文、実測のないランキング、無関係な装飾画像は置きません。
- 記事：短い題名→編集状態→短い結論→目次と本文→参考文献→確認範囲→関連記事。先に概要だけ読み、必要な範囲を掘り下げられるようにします。
- 色：紙に近い明るい背景、濃い本文、落ち着いた緑の操作色。各色を固定の役割に割り当てます。8分野を8色で塗り分ける構成は採用しません。
- デスクトップ：幅を制限した本文と左側目次。モバイル：一列の本文、開閉できる目次、短い見出し、必要に応じて横に送れる分類ナビ。

## コピーしない範囲

参考サイトの文章、写真、ロゴ、図版、固有の画面構成一式はコピーしていません。参考にしたのは分類、読み進め方、見出しの短さ、情報の優先順位などの構造です。CSS・HTML・記事本文はこのプロジェクト用に制作しています。

次の判断材料は、この版を使った実際のテーマ探索と記事読解のテストです。今回の比較だけで「最も使いやすい」と確定しません。
