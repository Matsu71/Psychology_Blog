# データ辞書（第3回拡張）

基本ファイル形式はschema_version 1.0を維持し、任意項目と独立台帳を追加しました。配置はDATABASE_ARCHITECTURE.md、採点はRANKING_METHOD.mdを参照してください。

## テーマ

既存のid,title_ja,concepts_en,angle_ja,search_query,priority,source_ids,caution_jaを維持します。priorityは旧版の編集優先度1/2で、新しい数値ランキングとは別です。related_topic_idsは関連、parent_topic_idsは派生元で、因果関係ではありません。

research_brief_idsは旧68件の研究メモ、source_review_idsは第3回の資料ごとの確認メモを参照します。daily_life_exampleは説明用の想定場面であり、実在の事例や実証済み介入ではありません。

manifestの既定値は全テーマに適用します。theme_candidate、not_assessed、publication_ready=falseのままです。source_idsが空のsearch_pendingは互換ラベルで、検索未実行とは限りません。

## 出典

書誌正本にはid,title,authors_display,year,journal,source_type,doi,url,verified_via_url,verification_scope,notes_jaを保存します。今回book_chapterを種別に追加しました。旧106件の個別レコードは変更していません。

source_typeのjournal_articleは掲載形態であり、原著実験・レビュー・訂正を意味する分類ではありません。研究デザインや訂正告知はrecord_roleとsource_reviewsで確認します。

verification_scopeは公式解説閲覧、書誌のみ、抄録、旧本文閲覧の従来値を保持します。今回さらに読んだ本文箇所はsource_assessmentsに追加し、既存の確認記録を上書きして過去の状態を失わないようにします。刊行年とオンライン日が異なる場合があり、不明な書誌は推測しません。

## source_reviews

id,source_id,topic_ids,design,review_scope,review_method,reviewed_on,key_findings_ja,limitations_ja,conclusion_direction,topic_relevance,relevance_scope,method_signalsを持ちます。review_scope=bibliographyの場合、key_findings_jaはnullです。abstractの場合も全文の査読相当の確認ではありません。formal_evidence_certaintyはnot_assessedです。

conclusion_directionはsupports,mixed,association,context,challenges,preliminary,not_evaluated。結果の方向が肯定的だから順位を上げることはしません。方法を厳密に揃えた正式な批判的評価ではなく、AI支援による単独の予備点検です。

## source_assessments

一つのsource_idにつき一件。確認段階、方法上の情報、限界、索引にある訂正等、本文で確認したsectionsとURLを保存します。formal_risk_of_biasとformal_evidence_certaintyは未評価を明示します。method_signalsがnullなら未再評価であり、低品質と断定した値ではありません。

selected_fulltext_checkは指定した本文箇所の点検です。全文・全補足・元データの独立検証や専門家監修を意味しません。

## evidence

一つのtopic_idとsource_idの組に一件。id,relation_role,relevance_1_to_5,relevance_scope,source_review_id,legacy_brief_ids,finding_scope_ja,conclusion_direction,limits_jaを持ちます。

直接・対象限定の根拠と背景資料を分けます。title_only_provisionalは題名・書誌の暫定対応。unassessed_legacy_linkは過去のリンクを保持しただけで、今回適合性を再評価していません。未評価を自動で5点にしません。

## 検索・ランキング

候補と検索履歴はliterature/catalog.jsonから全ファイルを辿ります。DOIとPMID等の別レコードやプレプリント・刊行版は同じ研究を表す場合があります。候補総数を独立研究数と表現しません。書誌・抄録の原文は候補台帳に保存しません。

編集ランキングは50テーマを個別評価、250件未評価。調査キューは300件。未評価テーマの作業配分に置いた50は実際の人気点数ではありません。点数の式・上限・同点の扱いはRANKING_METHOD.mdに固定しています。
