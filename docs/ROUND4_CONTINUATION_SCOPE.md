# 第4回・継続作業の目的と完了の定義

最終目的は、一般の読者が自分の生活と結び付けて楽しめる、科学的根拠を持つ300本の記事です。テーマ登録、文献の収集、ランキング、主張表、初稿は、それぞれ中間成果であり、記事300本の完成とは数えません。

## 品質の優先順位

各記事は、主張に直接対応する資料を確認し、対象者・条件・結果・限界を分けます。観察研究から因果を断定しません。生活の想定例と研究で実際に検証された介入を区別します。原論文の抄録を取得しただけで全文確認済みとしません。研究に数値の不整合がある場合は、その数値の使用を保留します。

## 今回の優先工程

未登録29テーマの資料補完、編集順位の上位20テーマの主張単位の根拠表、生活への応用、本文の作成、本文と根拠の再照合を順に進めます。ある工程を保存したことだけを終了理由とせず、実行できる範囲で次へ進みます。

## 状態管理

- `source_registered`：出典の書誌が確認できた状態。研究の結論を確認済みとは限りません。
- `claim_map_draft`：主張と資料の対応表を作成した状態。反証・訂正・適用範囲の検討を含みます。
- `article_draft`：読める本文の初稿。公開可能性の最終判定は別です。
- `reviewed_draft`：引用との対応・表現・生活への提案を再確認した稿。
- `publication_ready`：根拠・編集・安全性の必要な確認がすべて完了した稿。

公開済み・公開可能・下書きの件数を混同しません。実行枠の残量や過去の停止原因を確認できない場合、推測で強制終了や限界到達と説明しません。自動継続の仕組みを実行していない場合、応答終了後に作業が続くとは述べません。
