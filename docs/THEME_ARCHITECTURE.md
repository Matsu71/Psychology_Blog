# テーマ数と派生記事の設計

## 200を上限にしない

200や300という件数は編集・運用上の目安であり、科学的に最適と求めた数ではありません。テーマの保存数と実際に公開する記事数を分けます。今回の300件は記事候補の在庫で、300本を一斉に書く計画ではありません。

細かい題材だから面白くないのではなく、読者が直面する疑問が独立しているか、別の根拠が必要か、読み終えたときに得られる理解が違うかで判断します。例えば『カフェインと睡眠』から量と時刻を掘り下げることには意味がありますが、同じ研究・結論を飲み物の名前だけ替えて何本にも分割する必要はありません。

## 三層で管理する

| 層 | 内容 | 例 |
|---|---|---|
| 分野 | 全体を見渡すための分類 | 睡眠・体内時計 |
| 基本テーマ | 一つの独立した読者の問い | コーヒーは何時まで？カフェインと睡眠の個人差 |
| 研究・応用の切り口 | 対象、比較条件、生活場面、追試など | 摂取量と時刻を分ける、本人の体感と測定値を比べる |

基本テーマは記事をまとめる親ページにも使えます。研究論文一つにつき記事一本にする必要はありません。複数の研究を比較する記事、一般論と特定の生活場面の応用記事の双方を作れる構造にします。

## 今回追加した不足領域

仕事・働き方14件、お金・消費14件、恋愛・親密さ12件、身体感覚・健康行動12件、生活環境12件、創造性・遊び12件、言葉・語学12件、人生の変化・喪失12件の合計100件です。

『仕事後も頭が休まらない』『時間を買う支出』『家事の見えない負担』『暑い部屋で集中できない』『大人の語学』『失業や退職による変化』など、既存の用語を細分化するだけではない生活上の問いを補っています。新規100件すべてに個別の論文が付いたわけではありません。

## 重複を増やさない基準

新規テーマを追加する際は、読者の問題、必要な比較・研究、実生活での意味の少なくとも一つが実質的に違うか確認します。同じ説明で回答できるものは、一つのテーマの小見出し・具体例・関連キーワードとして扱います。

関連テーマを示す `related_topic_ids` は親子関係ではありません。因果関係も意味しません。明確な派生には `parent_topic_ids` を別に付けています。初期の例は、使わないサブスクとデフォルト・サンクコスト、健康の割合表示とフレーミング・効果量、問題をいったん離れることと創造的な休止です。すべてのテーマを無理に一つの親に結び付けません。

ID・既存の題名・順序は維持し、削除番号を別の話題に再利用しません。記事化の際に内容の重なりが判明した場合は、統合先と旧IDの対応を履歴に残します。

## 一般の読者への接続

基本構成は『身近な疑問 → 何を研究したか → 何が分かったか → 分からないこと → 日常での考え方』です。医療効果の保証や、相関を因果に変える誇張は避けます。身近な例の面白さと、結論の確かさは別々に管理します。

`study_context` は実際の研究の対象と条件です。`daily_life_example` は今回作成した説明用の想定場面で、実在する人の取材事例ではなく、その手順が直接検証済みという意味でもありません。実例を後から追加するときは出典と同意・プライバシーへの配慮を別に記録します。
