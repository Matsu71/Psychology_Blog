# 今後の作業順

現段階は調査です。テーマ数を増やすことより、出典の対応と品質を揃えることを優先します。実際の件数はdata/research/coverage.json、作業順はdata/rankings/research_queue.jsonを参照します。

## 1. 未登録と、書誌だけのテーマを直接資料で補う

検索を実行したこと、書誌を登録したこと、結果を読んだことを分けます。残る未登録テーマについて語句・対象・研究デザインを変えて検索します。心理学・教育・労働・消費分野ではEurope PMCに収載されない研究もあるため、出版社の原著・書籍章・事前登録・学術データベースを併用します。

完了条件は「最低一つの資料の題名を保存」ではなく、主要な問いを調べた資料を選び、その対象と限界を記録することです。直接の研究が見つからなければ、不足として残します。無関係な大規模論文で埋めません。

## 2. 編集上位の20テーマを研究メモとして厚くする

まずカフェイン、習慣形成、就寝先延ばし、通常の先延ばし、復習法、休憩、SNS制限、性格の変化などを候補にします。順位は編集上の仮説であり、調査で内容が薄いと分かれば統合・見送りができます。

基本テーマごとに、近年の質の高い統合研究、問いを直接調べた原著、独立した追試・反証を探します。「各3本」のような本数を固定せず、同じ参加者や同一研究の別版を独立した証拠として数えないことを優先します。

## 3. 主張単位の証拠表に進める

現在はテーマと資料の対応です。次は記事で述べたい一つの主張に対し、対象者・比較条件・測定結果・期間・効果量・信頼区間・研究デザイン・支持と反証・不確実性を整理します。例：「カフェインは睡眠に影響する」と「全員が正午以降飲まない方がよい」は違う主張として扱います。

本文、補足資料、事前登録との差、脱落・欠測、資金源・利益相反、独立追試、訂正・撤回・懸念表明を確認します。未確認はnullのまま残します。正式な確実性評価は、この工程を行ってから別のルールで実施します。

## 4. 一般読者向けの事例と適用範囲を検討する

「研究の中で実際に観察したこと」「説明用の想定場面」「生活で試せる提案」を明確に分けます。体験談は典型性や因果の証拠にはしません。日本の制度・生活・言語尺度・医薬品等の違いを確認し、治療に関わる内容は安全性の確認を経ます。

## 5. 執筆段階へ移る条件を決める

テーマを5～10本に絞って試作記事を作るのは、上記の研究メモと主張ごとの根拠が整ってからです。今はタイトルの煽り方やSEOより、読者が何を理解できるかを明確にします。公開判断・専門家確認・最終確認日・更新履歴を記録します。

自動の定期収集や記事公開は設定していません。このリストは実行済みの作業と区別した次工程です。
