# Psychology Blog — 人間の科学・ブログテーマデータベース

心理学に限定せず、睡眠、遺伝、性格、依存、学習、感情、対人関係、運動、食行動など、人間の行動と日常生活に関わる科学研究から、日本語ブログの記事テーマを収集するプロジェクトです。

**初版：20分野・200テーマ・35資料。** 日常生活につながる記事の問いと、研究を掘り下げるための入口を整理しています。記事本文やウェブサイトはまだ作成していません。

## 最初に読むこと

このデータベースは **記事のテーマ候補・調査入口** です。登録されていることは、その効果が実証済みであることや、医療上の推奨を意味しません。全200テーマのエビデンス評価は未実施で、公開可能な記事としては扱いません。

関連資料のリンクがあるテーマは84件、個別の出典調査待ちは116件です。リンクがあっても背景説明や書誌確認にとどまる場合があります。35資料には原著論文・レビュー・公的解説・参考文献一覧を含み、全資料の全文を精査したわけではありません。資料の確認範囲は [出典台帳](data/sources.json) に記録しています。

## データ構成

- [分類台帳](data/categories.json)：分野ID、ファイル、範囲、件数。
- [出典台帳](data/sources.json)：書誌、DOI、URL、確認範囲、注意点。
- [全体情報](data/manifest.json)：件数、未評価状態、調査優先度、初期候補12件。
- [データ辞書](docs/DATA_DICTIONARY.md) と [収集方針・記事化前の確認](docs/METHODOLOGY.md)。
- `scripts/validate.py`：JSON構文、重複キー・ID・題名、件数、参照整合性の検証と統合データ出力。

各テーマには、安定ID、記事タイトル候補、英語の研究概念、記事の切り口、追加検索用の文字列、調査優先度、関連資料ID、注意点を収録しています。検索文字列は検索実施済みの記録ではありません。

## 検証・一つのJSONへの統合

Python 3.9以降の標準ライブラリだけで実行できます。

```bash
python scripts/validate.py
python scripts/validate.py --export build
```

統合された `build/topics.json`、読みやすい `build/topics.md`、`build/validation_report.json` が生成されます。各レコードに分類と未評価状態を明示し、出典台帳も一緒に収録します。GitHub Actionsでも同じ検証を実行し、成功時は統合ファイルを実行結果のArtifactとして保存します。

## 科学的な取り扱い

日常の疑問を出発点とし、相関と因果、人と動物、健常者と患者、短期と長期を区別します。遺伝率を個人の遺伝割合と解釈せず、話題性・記事化優先度と証拠の強さを分離します。古典研究は追試・反証・訂正・撤回・近年の統合研究を確認してから記事化します。

DOI・年・効果量・標本数は推測で埋めません。論文全文や図表を無断転載せず、書誌と独自の整理を保存します。治療・薬・依存症・睡眠制限などは専門家による安全性確認を経て記事化します。
