# Psychology Blog — 人間の科学・ブログテーマデータベース

心理学に限定せず、睡眠、遺伝、性格、依存、学習、感情、対人関係、運動、食行動など、人間の行動と日常生活に関わる科学研究から、日本語ブログの記事テーマを収集するプロジェクトです。

## 最初に読むこと

このデータベースは **記事のテーマ候補・調査入口** です。登録されていることは、その効果が実証済みであることや、医療上の推奨を意味しません。記事本文の執筆・公開とは区別します。

- `data/topics/`：分野別テーマJSON。安定したIDで追記し、既存IDを付け替えない。
- `data/categories.json`：分類と範囲。
- `data/sources.json`：確認した資料・論文の書誌情報と確認範囲。
- `data/manifest.json`：件数・ファイル一覧・調査状況。
- `docs/`：収集方針、データ辞書、記事化前の検証手順。
- `scripts/validate.py`：JSON、重複ID、参照整合性などの検証。

## 科学的な取り扱い

1. 日常の疑問を出発点にし、心理効果名だけの雑学集にしない。
2. 相関と因果、人間と動物、健常者と患者、短期効果と長期効果を区別する。
3. 遺伝率を「個人の性格の何％が遺伝で決まる」と解釈しない。
4. 話題性・記事化優先度と、証拠の強さを別々に管理する。
5. 古典研究は歴史的入口とし、追試、反証、訂正、撤回、近年の統合研究を記事化前に確認する。
6. DOI・著者・年・効果量・標本数は確認できない場合に推測して埋めない。
7. 論文全文や図表は無断転載せず、書誌情報、リンク、独自の整理を保存する。
8. 治療・薬・依存症・睡眠制限などは専門家による安全性確認を経て記事化する。
